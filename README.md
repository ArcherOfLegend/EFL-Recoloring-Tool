# EFL Recoloring Tool

Recolours `.efl` effect files from Ultimate Marvel vs. Capcom 3.

## What it does

Finds every colour in the file and lets you change them. Yes this also includes those pesky secondary colors.

## Two Modes

**whole effect** - Recolor the effect wholesale.

**specific parts** - Recolor parts of the effect individually.

## Tint or Shift

**Tint** sets one hue across everything you've selected.

**Shift** rotates every hue by the same amount and leaves greys alone.

You can also set brightness and contrast... wow!

## Download

Grab the exe from [releases](../../releases).

If window says its protecting your PC just ignore it.

## Build it yourself nerd

needs the .NET 8 SDK.

```
git clone https://github.com/ArcherOfLegend/EFL-Recoloring-Tool
cd EFL-Recoloring-Tool
dotnet run
```
